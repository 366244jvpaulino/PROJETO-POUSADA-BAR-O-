# PROJETO-POUSADA-BAR-O-
O sistema tem como finalidade oferecer uma presença digital à Pousada Barão, localizada no centro de Araras – SP. O site permite que clientes e empresas conheçam os serviços, visualizem os quartos disponíveis e entrem em contato ou solicitem uma reserva de forma simples, sem necessidade de deslocamento físico. O sistema delimita suas funções ao ambiente informativo e de contato, não contemplando pagamentos ou confirmações automáticas.

Informações gerais:
- Plataforma: Aplicação web (PHP + CSS)
- Ambiente: PHP Server + VS Code
- Usuários: Clientes e empresas
- Localização: Araras – SP, Brasil

Funcionalidades do sistema:
- Página inicial com apresentação da pousada, serviços e quartos disponíveis
- Formulário de solicitação de reserva com seleção de quarto e datas
- Formulário de contato com gravação das mensagens recebidas
- Cadastro e login de clientes e empresas com controle de sessão
- Mapa de localização e página de atrações próximas à pousada
- Botão direto para WhatsApp e link para o Instagram da pousada

Limites do sistema:
Dentro do escopo: site responsivo, exibição de quartos e serviços, solicitação de reserva por formulário, contato via WhatsApp e Instagram, cadastro e login de usuários.
Fora do escopo: pagamento online, confirmação automática de reserva, painel administrativo, aplicativo mobile, sistema de avaliações.
